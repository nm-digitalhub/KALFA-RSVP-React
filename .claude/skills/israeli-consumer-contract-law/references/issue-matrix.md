# מטריצת סוגיות — ששת חוקי הליבה

| סוגיה | חוק עיקרי | בדיקות משלימות |
|---|---|---|
| כריתת חוזה והסכמה | חוק החוזים (חלק כללי) | חתימה אלקטרונית; הגנת הצרכן |
| מצג מטעה או אי-גילוי | חוק הגנת הצרכן (§2) | טעות/הטעיה ותום לב בחוק החוזים |
| ביטול עסקה צרכנית | חוק הגנת הצרכן (14ג/14ה) | תרופות, ביטול והשבה |
| סעיף חד-צדדי או פטור מאחריות | חוק החוזים האחידים (§3/§4) | הגנת הצרכן; תקנת הציבור |
| הפרה ואי-אספקה | חוק החוזים (תרופות) | חוק הגנת הצרכן; חוק המכר לפי הצורך |
| חוזה באתר או באפליקציה | חוק החוזים + חתימה אלקטרונית | גילוי, נגישות תנאים וביטול צרכני |
| פרשנות חוזה אחיד/צרכני | חוק החוזים (חלק כללי) §25 אחרי תיקון 3 | חוזים אחידים (פירוש-נגד-המנסח בלתי-נתיק) |
| חיוב מתמשך או מנוי | חוק הגנת הצרכן (13ג) | חוזה אחיד; תרופות |
| פרקטיקה רוחבית | חוק תובענות ייצוגיות | עילת צרכן אישית; התוספת השנייה |
| פיצוי מוסכם | חוק החוזים (תרופות) §15 | תנאי מקפח בחוזה אחיד |
| מחלוקת על חתימה | חוק חתימה אלקטרונית | דיני ראיות, כריתה ונטלי הוכחה |

## כלל עבודה

בשאלה חוזית/צרכנית אין לבחור חוק אחד בלבד. יש לעבור על כל ששת החוקים ולסמן:
- חל;
- אינו חל;
- נדרש מידע נוסף;
- נדרש חוק משלים.
