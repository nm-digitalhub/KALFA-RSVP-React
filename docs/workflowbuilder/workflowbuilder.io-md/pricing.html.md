## Questions teams ask before they buy

-   Is Workflow Builder the same as Builder.io?
    
    No. Builder.io is a visual page builder for marketing sites. Workflow Builder is a React SDK for embedding production workflow editors into B2B SaaS products. Different category, different buyer, different problem.
    
-   What is included in the Enterprise license?
    
    EUR 6,990 one-time gets you source code access to Enterprise-only components (Flow Runner plugin, Figma Kit, advanced canvas plugins: ELK auto-layout, smart edge routing, edge reshaping) and priority GitHub issues. Community Edition (Apache 2.0) already includes the visual workflow editor, reference back-end, and Temporal adapter, so you do not need Enterprise to ship a working workflow product.
    
-   Is the reference back-end gated behind Enterprise?
    
    No. The reference back-end is part of Community Edition. Apache 2.0 license, full source on GitHub, including the Temporal integration adapter. Enterprise adds Enterprise-only components on top - Flow Runner plugin, Figma Kit, dedicated support. [See what is in the reference stack →](https://www.workflowbuilder.io/reference-stack)
    
-   Can I use Workflow Builder Community in a commercial product?
    
    Yes. Apache 2.0 is a liberal license. Commercial use is OK, modification is OK, no copyleft. You can build and sell a product on top of Workflow Builder Community Edition without a commercial license. [See the open source story →](https://www.workflowbuilder.io/open-source)
    
-   Is the EUR 6,990 a subscription or one-time?
    
    One-time, per organization, unlimited developers. Perpetual license to use the Enterprise components in your products. No annual renewal required.
    
-   Do I have to use Temporal?
    
    No. Temporal is the reference engine adapter shipped today. You can swap it for Inngest, Camunda, AWS Step Functions, Cloudflare Workflows, or your own in-house engine using the same port interfaces (WorkflowEnginePort, ActivityRunnerPort, EventEmitterPort). [See engine integrations →](https://www.workflowbuilder.io/reference-stack)
    
-   What is the Workflow Setup Sprint?
    
    A 2-4 week kickoff sprint that pairs you with our engineering team. Architecture review, AI dev environment setup with Claude skills and scaffolding tools, integration plan with your back-end, transfer to your team, plus 30 days of post-handover support. EUR 15,000 to EUR 25,000 depending on scope. Requires an Enterprise Edition license (EUR 6,990), so our team works in the same codebase as you with full source access.
    
-   Do I need Enterprise Edition for the Workflow Setup Sprint or End-to-end services?
    
    Yes. Both partner-led options require an Enterprise Edition license (EUR 6,990 one-time). The Enterprise license unlocks source code access to the components our team works with: Flow Runner plugin, Figma Kit, advanced canvas plugins. Community Edition (Apache 2.0) is self-serve; partner-led delivery starts at Enterprise. Either way, the Enterprise license is yours perpetually, even after the engagement ends.
    
-   Do you offer an Enterprise SLA?
    
    Yes, on-demand. Enterprise SLA is available for Enterprise Edition customers, so [contact sales](https://www.workflowbuilder.io/contact) to discuss your specific requirements. Terms (response times, escalation paths, coverage hours) are negotiated individually based on your team size, deployment scale, and operational needs.
    
-   Will Apache 2.0 ever change to BSL or SSPL?
    
    No. Apache 2.0 is our hard commit. We watched the MongoDB SSPL, Elastic SSPL, HashiCorp BSL, and Redis SAL relicensing events. Workflow Builder Community Edition stays Apache 2.0. The full source on GitHub is yours under that license, perpetually.
