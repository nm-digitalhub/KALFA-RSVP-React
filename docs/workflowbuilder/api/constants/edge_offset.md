# EDGE_OFFSET

`const` **EDGE_OFFSET**: `20` = `20`

Pixel gap between an edge endpoint and the connected node’s bounding box. Tunes the smooth-step routing used by [LabelEdge](https://www.workflowbuilder.io/docs/api/components/labeledge/).
