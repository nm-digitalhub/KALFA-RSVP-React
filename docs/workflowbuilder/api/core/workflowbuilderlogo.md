# WorkflowBuilderLogo

**WorkflowBuilderLogo** = `string` | { `dark`: `string`; `light`: `string`; } | `ReactElement`

App-bar logo accepted by `<WorkflowBuilder.Root>`: an image URL, per-theme image URLs, or a custom element.
