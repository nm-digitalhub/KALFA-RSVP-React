# IfThenElseSchema

**IfThenElseSchema** = `object`

Conditional validation block in a [NodeSchema](https://www.workflowbuilder.io/docs/api/types/nodeschema/) — when `if` matches, `then` rules apply; otherwise `else` rules apply. Mirrors the JSON-schema [if/then/else](https://json-schema.org/understanding-json-schema/reference/conditionals) shape, narrowed to the field-validation subset the SDK uses.
