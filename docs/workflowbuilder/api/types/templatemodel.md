# TemplateModel

**TemplateModel** = `object`

One entry in the editor’s template selector — pairs a [DiagramModel](https://www.workflowbuilder.io/docs/api/types/diagrammodel/) with display metadata (id, name, icon). Pass an array of these to `<WorkflowBuilder.Root diagramTemplates={...} />` to populate the selector.
