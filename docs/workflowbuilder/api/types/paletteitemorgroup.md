# PaletteItemOrGroup

**PaletteItemOrGroup** = [`PaletteItem`](https://www.workflowbuilder.io/docs/api/types/paletteitem/) | `PaletteGroup`

Either a single [PaletteItem](https://www.workflowbuilder.io/docs/api/types/paletteitem/) or a labelled group of them (`PaletteGroup`). `<WorkflowBuilder.Root nodeTypes={...} />` accepts a mixed array of both forms.
