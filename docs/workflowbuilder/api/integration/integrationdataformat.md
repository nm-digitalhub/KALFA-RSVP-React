# IntegrationDataFormat

**IntegrationDataFormat** = `object`

Canonical persistable shape of a workflow document. Returned by [getStoreDataForIntegration](https://www.workflowbuilder.io/docs/api/store/getstoredataforintegration/) and passed to the host’s save callback under the `'props'` strategy.
