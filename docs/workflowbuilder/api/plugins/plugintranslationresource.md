# PluginTranslationResource

**PluginTranslationResource** = `object`

i18next-shaped resource bundle accepted by [registerPluginTranslation](https://www.workflowbuilder.io/docs/api/plugins/registerplugintranslation/). Every plugin’s strings live under `translation.plugins.<pluginName>` to namespace away from SDK keys.

## Index Signature

[`lang`: `string`]: `object`
