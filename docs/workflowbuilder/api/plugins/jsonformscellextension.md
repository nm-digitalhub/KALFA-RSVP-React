# JsonFormsCellExtension

**JsonFormsCellExtension** = `JsonFormsCellRendererRegistryEntry`

Custom JsonForms cell renderer — like [JsonFormsRendererExtension](https://www.workflowbuilder.io/docs/api/plugins/jsonformsrendererextension/) but for cell-level rendering inside table-style controls.
