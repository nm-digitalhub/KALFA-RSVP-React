# React Component

Embed Workflow Builder in any React app.

## Requirements

- React 18 or 19

- `@xyflow/react` 12 or higher

- ESM-compatible bundler (Vite, Webpack 5, Next.js, Parcel)

## Known limitations

Caution

Mount only one `<WorkflowBuilder.Root>` per page. Multi-instance is not supported. See [Side effects & limitations](https://www.workflowbuilder.io/docs/get-started/side-effects/) for the details and how to swap workflows on one page.

## Installation

Install the SDK along with its peer dependencies:

-  npm

-  pnpm

-  yarn

Terminal window
```bash
npm install @workflowbuilder/sdk @xyflow/react zustand
```
Terminal window
```bash
pnpm add @workflowbuilder/sdk @xyflow/react zustand
```
Terminal window
```bash
yarn add @workflowbuilder/sdk @xyflow/react zustand
```
Requires React 18 or 19. Everything else the SDK uses (JsonForms, i18next, immer, …) is a regular dependency and installs automatically.

## Usage

The SDK exposes a single compound component, `WorkflowBuilder`. Mount `<WorkflowBuilder.Root>` at the top of your editor subtree; with no children it renders the default layout (top bar, palette, canvas, properties panel).

`<WorkflowBuilder.Root>` takes a small set of optional props. See [Configuring the editor](https://www.workflowbuilder.io/docs/guides/configuring-the-editor/) for the full props reference and for composing a custom layout, or the auto-generated [API reference](https://www.workflowbuilder.io/docs/api/core/workflowbuilderroot/).

### Hello world
```tsx
import { WorkflowBuilder } from '@workflowbuilder/sdk';

import '@workflowbuilder/sdk/style.css';

function App() {
  return (
    <WorkflowBuilder.Root
      name="my-workflow"
      layoutDirection="DOWN"
      nodeTypes={
        [
          /* PaletteItemOrGroup[] */
        ]
      }
      integration={{
        strategy: 'props',
        onDataSave: async (data) => {
          console.log('Saving:', data);
          return 'success';
        },
      }}
    />
  );
}
```
