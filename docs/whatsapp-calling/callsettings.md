Call hours Use this API to update the settings. This updates the same setting on Meta Business Suite and the Messenger app. To set the call hours for a Page, make an API request to the messenger_call_settings endpoint and set call_hours . Updates in existing chats are near real-time. When you set hours, any previous settings are erased. Any days you don't set default to closed. By default, the call icon visibility will be set to true for all pages. When icon_enabled is set to false , the call icon will not be shown for all threads for that page. Additionally, users will not be able to initiate calls from Missed Call or Completed Call messages when icon visibility is turned off. Businesses can send a Call Prompt message to allow the user to call the business. Businesses will call this API to enable/disable the call icon for the page. Send a Call Prompt Message Using Messenger Send API The business can send a new template call_prompt . This new template contains a button that will allow the consumer to initiate a call with the business. The consumer will only be able to initiate the call for the number of days specified by the business when the message is sent. The business can use ttl_days to specify how many days the calling button will be active for the consumer. If ttl_days is not specified, by default the calling button will only be active for 7 days.
