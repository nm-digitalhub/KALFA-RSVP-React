## מה זה
Eleven v4 Turbo הוא מודל ה-TTS של ElevenLabs שמיועד לשיחות בזמן אמת. הוא זמין כעת בתוך ElevenAgents לסוכני שיחה, כולל שיחות טלפון, ביותר מ-90 שפות.

## יכולות מרכזיות
| יכולת | תיאור |
|---|---|
| התאמת טון במהלך שיחה | הסוכן מזהה תסכול, היסוס או לחץ אצל המתקשר ומשנה את הטון בהתאם. אפשר לכוון אותו עוד באמצעות audio tags והקשר השיחה. |
| 90+ שפות ומבטאים | כל קול יכול לדבר בכל שפה שהסוכן תומך בה, ולהחליף שפה באמצע שיחה. |
| Turn-taking | כשהמתקשר מתפרץ, הסוכן עוצר באמצע מילה, קולט את התיקון ועונה על השאלה החדשה באותו תור. |
| עקביות קול | זהות הקול נשמרת בין תורות ובין שפות. |
| סביבה אקוסטית | אפשר להוסיף רקע וצליל חדר, למשל סטודיו שקט, משרד, או סאונד באיכות טלפוניה. |
| Streaming | הטקסט מומר לאודיו תוך כדי יצירתו, כך שהתשובה מתנגנת ברגע שהיא מוכנה. |
| Pronunciation control | כללי פונמות או IPA inline לשמות מותגים, מונחים טכניים ושמות מקומות. |
